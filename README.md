# Autonomous Viral Video Generator

## Overview
This skill empowers the AI agent to operate as an **Autonomous Video Production House & TikTok Media Studio**.
It specializes in producing high-retention vertical short-form content (9:16) for:
- **TikTok Creator Rewards Program** (Targeting US/Global high-RPM viewers)
- **TikTok Shop & Affiliate Traffic** (Vietnamese & Regional e-commerce)

---

## 🎬 Core Architecture & Capabilities

1. **Curated Hook-Driven Scripting (Bilingual):**
   - Automatically drafts 30-60 second scripts optimized for retention:
     - **0-3s:** Strong pattern-interrupt hook.
     - **3-45s:** Rapid story delivery / mind-bending scientific facts.
     - **45-60s:** High-converting Call-to-Action (CTA).
   - Generates parallel versions in **English** (`en-US`) and **Vietnamese** (`vi-VN`).

2. **Neural Voice Synthesis (Edge-TTS Engine):**
   - High-fidelity natural voiceovers without expensive API keys:
     - `en-US-GuyNeural` / `en-US-JennyNeural`
     - `vi-VN-HoaiMyNeural` / `vi-VN-NamMinhNeural`

3. **Viral Metadata & Hashtag Optimization:**
   - Prepares optimal TikTok descriptions, high-traffic niche hashtags (`#science`, #learnontiktok`, `#kienthuc`).

4. **Automated Publishing Workflow:**
   - Integrates with Playwright browser session profiles to schedule uploads directly at prime-time slots (11:30 AM & 7:30 PM).
